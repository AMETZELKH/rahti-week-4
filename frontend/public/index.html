Documentation

Application

This application is a simple visitor counter running on Rahti. The frontend communicates with a backend REST API, and the backend reads and writes data in a MySQL database.

Frontend - Backend - Database

The frontend communicates with the backend through the Kubernetes Service backend. The backend connects to MySQL through the mysql Service. The application was tested by creating and retrieving data through the frontend. The returned data confirms that the request travelled through the frontend and backend and was stored in MySQL.

Docker Compose vs Rahti

The previous Docker Compose deployment ran containers using a Docker network and Docker volumes. In Rahti, Kubernetes resources such as Deployments, Services, Routes and PersistentVolumeClaims manage the application, networking and storage.
